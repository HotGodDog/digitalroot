# Digital Root

Простая Python библиотека для вычисления цифрового корня числа.

## Что такое цифровой корень?

**Цифровой корень** — это результат повторного сложения цифр числа, пока не останется одна цифра.

### Примеры:
- `123` → 1+2+3 = **6**
- `987` → 9+8+7 = 24 → 2+4 = **6**
- `999` → 9+9+9 = 27 → 2+7 = **9**
